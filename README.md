## Experiment 01 — LED Control via Smartphone App

This experiment demonstrates controlling an external LED using an Arduino Uno.

The Arduino receives commands through serial communication:

- `1` → Turns the LED **ON**
- `0` → Turns the LED **OFF**

The circuit is simulated using **Tinkercad**.

### Concepts Covered

- Arduino Uno
- Digital Output
- LED Interfacing
- Serial Communication
- Basic IoT Control Concept
- Circuit Simulation using Tinkercad
